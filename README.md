uses Random and Flixel

# controls
- `ESC / BACKSPACE` exit to main menu
- `WASD / ARROW KEYS` move around in game
- `SHIFT / CONTROL` move 2x faster while moving
- `MOUSE WHEEL` zoom in and out
- `E / Q` timescale up and down

- `CLICKING AN ANIMAL` shows an animals stats on the top left
- `CLICKING OFF AN ANIMAL` hides the stats from that animal

# libs
* `flixel` `haxelib install flixel 6.2.0`
* `random` `haxelib install random 1.4.1`
